# Smart Dorm · Frontend

Personal portfolio project derived from [vue3-element-admin](https://gitee.com/youlaiorg/vue3-element-admin). The original MIT license and attribution to PanJiaChen and 有来开源组织 are retained in [LICENSE](LICENSE).

Building, room and student pages exist; full CRUD integration is not verified. No accommodation workflow or AI Agent is implemented. See [README.md](README.md) for setup and evidence. VITE_* variables are public browser configuration: never store server/model keys here. GitHub creation/push is pending CLI authentication.
